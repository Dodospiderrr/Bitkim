Aşama1--> Bembeyaz bi Uygulama Olusturma

Expo Go üzerinden webde çalışıcak (şimdilik) boş bir uygulama oluşturdum.

Bin tane dosya olustu
PACKAGE.JSON projenin kimlik kartı: ismi, versiyonu, sürüm scriptleri kullanılan kütüphaneler falan en önemli seyler var silinirse sıctık
PACKAGE-LOCK.JSON: Hangi kütüphanelerin kullanıldığını söyleyerek bosuna uğrasmayı önlüyo silinirse ortalık karısıyo
NODE_MODULES: Projede kullanılan tüm kütüphaneler var. Silinirse npm install yapar hallederiz.
APP.JSON: Uygulamanın adı açılış ekranı ikonları platform ayarları falan var.

Öğrendiğim 3 kavram
1.Kütüphane: Başkaları tarafından önceden hazırlanmış kodlar. Lego parçaları gibi bunlarla ne yapıcağın sana kalmış ama
2.npx: Yüklü olmayan Node dosyalarını bilgisayara indirip geçici olarak çalışmasını sağlayan ön komut
3.npm: Javanın resmi paket yükleme platformu.
